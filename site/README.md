# The website of A Method for Prayer

The homepage and the privacy page. Next.js builds a static export to `out/`.
Run `npm run site` at the repository root to build the app and the homepage
together. That command puts the app in `out/app/`.

```bash
npm install
npm run dev      # the homepage on http://localhost:3000, without the app
```

The design comes from the Primer template of Tailwind Plus, as on hearers.app.
`LICENSE.md` holds the licence of the template.
